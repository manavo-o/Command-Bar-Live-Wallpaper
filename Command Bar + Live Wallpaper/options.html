Using the Command Bar

Enter
Search, or execute a selected result. Math answers and symbolic previews, definitions, and synonyms can be copied; missing words open Apple Dictionary.
↑ / ↓ · Tab / Shift+Tab
Navigate results. Ctrl+J / Ctrl+K also move down and up.
→ / Tab · Backspace
Accept inline autocomplete with Right Arrow or Tab. Backspace cancels the selected completion.
Escape
Close the command bar. Its configured shortcut also toggles it.
Shift+Enter
Search with Google. Configured custom search shortcuts appear under Custom Search Engines below.
@history · @bookmarks
Search a specific source. Use /allwindows to include tabs from every window.
/ · math · define word
Find actions, enter an expression or solve command, or look up a definition. Math cards automatically format powers, fractions, and roots.

Custom Search Engines

Use Shift+Enter for Google. Ctrl/Alt/Meta+Enter can open configured custom engines. Plain Enter keeps the normal command-bar behavior.

About

Command Bar & Live Wallpaper

Version

Wallpapers, preferences, and cached icons are stored locally. Tabs, history, and bookmarks power command-bar results. Type “calm def” for a definition or “calm syn” for synonyms. Word lookups check spelling automatically. Enabled search suggestions send your query to Google; definitions use FreeDictionaryAPI; spelling checks and synonyms use Datamuse. Weather and city lookup use Open-Meteo. Icon discovery uses browser caches, icon links from open tabs, and direct favicon files without credentials. No third-party favicon service is used. All-sites access enables the overlay and icon discovery; unlimited storage supports large video wallpapers.
